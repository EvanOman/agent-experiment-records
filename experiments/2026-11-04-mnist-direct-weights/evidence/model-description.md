# Directly authored digit model

This experiment uses a fixed template/RBF-style numerical classifier. Native OpenAI GPT-6 Astra Ultra agents directly authored 192 generic digit forms as literal stroke-coordinate arrays, widths, and class assignments. A data-free renderer expands every form at the three authored shared width multipliers `[1, 1.5, 2]`, producing 576 template units per preprocessing view. These are generic handwriting constructions, not copied or fitted MNIST examples. The original sources and authoring notes accompany each candidate.

The renderer computes distance to the authored line segments on a fixed 64×64 canvas, applies the explicitly defined stroke boundary, and passes the result through the same normalization and feature equations used for input pixels. The resulting numerical tensors are saved exactly. This is deterministic geometric/feature expansion of authored patterns; it is more than byte serialization and uses no image dataset.

The selected architecture consumes only N×28×28 uint8 pixels. Bounding-box normalization and moment deskew are fixed image-only equations. Two views use deskew strengths 1 and 0.5, with equal output weights. Each 24×24 normalized image produces two shared brightness channels and eight rectified oriented-gradient channels. Fixed local orientation normalization and per-image feature-energy normalization reduce contrast/width sensitivity without estimating any dataset statistic.

A 4×4 tree of spatial parts compares each image with every authored template. Hidden states represent fixed spatial displacements. Shared quadratic displacement and neighboring-part consistency penalties, a fixed two-pixel edge constraint, and minimum pooling permit coherent deformation. The comparison is symmetric and retains undeformed and coarse brightness terms. The complete precision candidate c026 uses all 81 integer offsets on `[-4,4]²`; its numerical penalties and feature graph are the same as c024. The actual state table is row-major (y outer, x inner), with the zero state at index 40; the graph detects it from coordinates. Pooling computes activations, never weight updates.

A shared auxiliary branch evaluates ten literal 2×2 pattern convolutions on three intensity thresholds of raw and blurred normalized pixels. Fixed output coefficients produce six Euler-characteristic features. A small capped template discrepancy supplies closure evidence. All templates and all input images use the same branch; there are no digit-specific procedural rules.

Class scores pool over the fixed authored template assignments, average the two preprocessing views, and apply the one directly authored ten-number bias vector recorded in the parameter JSON and its provenance note. No labels, sample IDs, filenames, positions, hashes, dataset membership, or mutable sample cache enter inference.

Development has used only designated working/validation partitions. Agents may inspect their activations and error reports and then directly author a reasoned numerical revision. No gradient, conventional training, regression, class centroid, automatic weight search, pretrained classifier, downloaded weights, or web access was used. Each evaluated candidate preserves its authored sources, expanded tensors, graph snapshot, hashes, reason, and separate immutable evaluation report. Repeated validation is development evidence; success requires the separately frozen, independently reviewed, one-use withheld confirmation result.
